Online Game Store Database
Описание проекта

Проект представляет собой базу данных для интернет-магазина компьютерных игр. В базе хранятся данные о пользователях, играх, разработчиках, издателях, жанрах, игровых платформах, заказах и оплатах. Основными пользователями системы являются покупатели и администраторы магазина. Покупатели могут выбирать игры, добавлять их в корзину, оформлять заказы и оставлять отзывы. Администраторы могут управлять каталогом игр, отслеживать заказы и проверять информацию об оплатах. База данных помогает организовать информацию о товарах и покупках, а также упрощает управление магазином. Я выбрал эту тему, потому что интересуюсь компьютерными играми и хотел разобраться, как реляционные базы данных используются в интернет-магазинах.

Требования

Для работы с проектом необходимы:

PostgreSQL 18.
pgAdmin или терминал psql для выполнения SQL-команд.

Запуск
Создать новую базу данных PostgreSQL.
Открыть базу данных в pgAdmin.
Открыть Query Tool.
Открыть файл migrations/01_init.sql, скопировать его содержимое и выполнить в Query Tool.

После выполнения скрипта таблицы будут созданы и заполнены начальными данными.

Проверка

Чтобы проверить наличие таблиц в схеме games, выполнить запрос:

SELECT table_name
FROM information_schema.tables
WHERE table_schema = 'games'
ORDER BY table_name;

Чтобы проверить количество записей в трёх таблицах-справочниках, выполнить:

SELECT COUNT(*) FROM games.genres;
SELECT COUNT(*) FROM games.platforms;
SELECT COUNT(*) FROM games.publishers;

Каждый из трёх запросов должен вернуть значение 10.
